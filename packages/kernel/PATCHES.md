# Kernel patches

Base: kernel.org `v7.2.12` (`SOURCE.env`). `patches/series` applies in order with `patch -p1 -F0`, zero fuzz.
The patches are the TB321FU subset of `enij90/armada-tb321fu` tag `v20261024.0146e89` (`packages/kernel/patches/`),
which carries the sources and upstream status of each patch in its own `PATCHES.md`. Two patches have the context
refreshed for 7.2.12 and one (`0048a`) is already in 7.2.12. The DTS files are `dts/sm8650-lenovo-tb321fu.dts` and
`dts/sm8650-lenovo-tb321fu-csot.dts`, copied into `arch/arm64/boot/dts/qcom/` by `build.sh`.

Config: `tb321fu.config` is the Armada override fragment without comments, `microos.config` the image level lines.
